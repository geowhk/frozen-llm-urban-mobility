# Reproducibility contract

## October 2026 release preparation

The launcher was renamed to `run_paper1.py` to remove package shadowing. Figure 2
now labels arrival hour as t, matching the TGIS manuscript. No fitting or metric
arithmetic was changed. The R geometry comment explicitly distinguishes current
distance geometry from historical prompt coordinates.

The September 28 AWS evidence supplement matched the stored cache, row-index,
metadata and prompt-source files to local artifacts and reconstructed tokenization
from an archived snapshot. It did not rerun model forward passes or establish
the exact historical runtime. Thus the limitations below still apply. The private
AWS logs are not part of this release. The lineage JSON records the initial cleanup
baseline; the comment-only R change and Figure 2 notation change supersede its
original byte-identical/visual-identical descriptions for those two files.

## What was verified during cleanup

Nine synthetic/original unit tests passed. The accepted snapshot passed 228 read-only checks. Fixed OOF evaluation and figure/table generation were rerun without model fitting; common numeric CSV outputs were compared to the accepted snapshot with rtol=1e-10 and atol=1e-8. Some fit-only CSVs are copied, not recalculated; their preservation is not an independent re-fit verification.

## Required private bundle

The accepted package must contain `config.json`, `inputs/` (mobility, prompt source, saved outer/inner splits, audited OOF, district names, bins and prior diagnostics), and `results/oof_predictions_all_models.parquet`. Its `CHECKSUMS.sha256` is verified when present. Predictions use 14,400 directed OD-hour rows, 300 reciprocal dyads, five saved outer folds. `y_gt` is a historical column name for mobility estimates, not a claim of error-free ground truth. Model/column names are centralized in `src/paper1/config.py`.

For the original-model audit, private data additionally requires `processed/gt_flow_gu_202411_weekday_daily.parquet` and `analysis_cache/{original,geometry}/`. `--archived-final` supplies the original saved splits/candidates/results used by the audit. Do not substitute other folds or recompute coordinates when reusing cached representations. The cache's historical prompt coordinates and new distance geometry have distinct provenance.

## Training conventions retained

Training-subset feature statistics only; log1p targets are mean-centered, not divided by a target standard deviation. Inner fits select penalties; full outer-training fits produce held-out predictions. The polynomial comparator standardizes the six base features, expands to 27 degree-2 terms without a bias term, then standardizes expanded features. Arrival-hour cyclic features are sin(2πh/24) and cos(2πh/24). Existing saved splits and configuration are authoritative.

## Limits

- This cleanup did not rerun raw preprocessing, LLM inference, or original/full comparator training. Synthetic fit tests are not a substitute for those runs.
- Preserved representation primitives are source provenance, not a complete end-to-end LLM extraction CLI. The historical driver depended on additional project modules. Exact model/tokenizer revision information is incomplete; bit-for-bit regeneration of caches is not established.
- Numeric libraries, R packages, model revisions, source-data access and redistribution rights must be finalized before a fully independent public reproduction claim.
- `docs/source_lineage.json` points to original relative workspace sources. Formatting and module boundaries changed; historical source files remain byte-preserved in the private archive.
- Figure 1 is a manuscript asset, not generated by this analysis pipeline.
